# SmartLab Guardian: Secure and Automated Laboratory Control System
*(ARM Mini Project - Vector India)*

An IoT and Embedded Systems-based laboratory automation and security management project built using ARM architecture, designed to monitor environmental parameters, enforce RFID access control, and provide automated safety overrides.

## Project Structure
- `firmware/` - Embedded C source code, startup files, and peripheral drivers (GPIO, UART, Timers, Interrupts, SPI/I2C)
- `hardware/` - Circuit schematics and pin configuration diagrams
- `docs/` - Project documentation, block diagrams, and flowcharts
